# Fixes after v1 build, 2026-11-20

Found on the phone (SM-S906E, Android 16, release build) and by comparing `main` with `prototype/app`. The reference for each screen is the prototype variant that the spec's "Screens" section describes. Marked **bug**, **gap** (differs from the prototype or spec) or **content** (Coach wording/prompts).

Not a Waypoint issue: the floating circle with four squares is Samsung's Assistant Menu (an accessibility setting).

## Cross-cutting

- [x] **gap** Appearance setting in Settings: System · Light · Dark, default System. Following the system already works (`adaptiveThemes`, `userInterfaceStyle: automatic`).
- [x] **bug** Keyboard: replace `app/src/coach/useKeyboardHeight.ts` with `react-native-keyboard-controller` in both chats. Today it pads on `keyboardDidShow`, so the input bar jumps once the keyboard has finished opening. On the Coach tab the padding overshoots by the tab bar height. On the Interview the input ends up behind the keyboard. _Done: both chats sit in `ui/KeyboardPadded`, which follows `react-native-keyboard-controller`'s animated height frame by frame (its own `KeyboardAvoidingView` mis-measured on this phone). Checked on the phone._
- [x] **bug** Dates: one locale formatter everywhere (for example "Sun 22 Nov", with the year only when it isn't this year). Plan review's Two weeks and the Interview picture show ISO dates. The Aspiration screen shows "July 15, 2027".
- [x] **bug** Chat auto-scroll: both chats call `scrollToEnd({animated:true})` whenever the last message's text changes (`app/src/app/interview.tsx:142`, `app/src/app/(tabs)/coach.tsx:84`), so every streamed chunk scrolls. It should follow the bottom only while the user is at the bottom. _Done: both chats use an inverted `ui/chat/ChatList`, so no scrolling code runs. Also fixed a deeper bug: every Coach message showed "can't reply right now" and Saved, because the offline send never reported success and a reload marked the queued message unanswered. Checked on the phone from a cold start._
- [x] **gap** Markdown: Coach bubbles render bold, italics and bullet lists. The prompts also ask for plain prose.
- [ ] Smoothness on other screens: re-check on the release build after the chat fixes. _Chat checked on the release build. Other screens not separately profiled._
